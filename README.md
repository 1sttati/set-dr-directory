# ทำเนียบ DR ตลาดหุ้นไทย

เว็บรวมรายชื่อ DR (Depositary Receipt) ทั้งหมดบน SET จัดกลุ่มตามหุ้นแม่/ETF ที่อ้างอิง ค้นหาได้ทั้งชื่อ DR, หุ้นแม่, ธีมธุรกิจ, ประเทศ พร้อมลิงก์ไปกราฟ TradingView ของหุ้นอ้างอิง

**Demo:** https://<username>.github.io/dr-directory/

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (HTML/CSS/JS ไฟล์เดียว) โหลดข้อมูลจาก `data/dr.json` ตอนเปิดหน้า |
| `data/dr.json` | ข้อมูลหุ้นแม่และ DR ทุกรุ่น |

## Format ข้อมูล (`data/dr.json`)

```json
{
 "symbol": "AAPL",
 "name": "Apple Inc.",
 "desc": "iPhone, iPad, Mac และบริการดิจิทัล หนึ่งใน Magnificent 7",
 "drs": ["AAPL01", "AAPL03", "AAPL19", "AAPL80"],
 "country": "us",
 "type": "stock",
 "tv": "AAPL"
}
```

- `country`: `us` / `cn` / `jp` / `vn` / `sg` / `tw` / `eu`
- `type`: `stock` / `etf`
- `tv`: symbol บน TradingView รูปแบบ `EXCHANGE:TICKER` (เช่น `HKEX:700`, `TSE:7203`) — ไม่ใส่ = ไม่แสดงลิงก์กราฟ
- เลขท้ายชื่อ DR = รหัสผู้ออก: 01 บัวหลวง, 03 พาย, 06 เกียรตินาคินภัทร, 11 กสิกรไทย, 13 KGI, 19 หยวนต้า, 23 InnovestX, 24 ฟินันเซีย ไซรัส, 80 กรุงไทย

## แก้ไข/เพิ่มข้อมูล

แก้ `data/dr.json` อย่างเดียว ไม่ต้องแตะ `index.html` — เพิ่ม DR รุ่นใหม่ให้เติมใน `drs` ของหุ้นแม่เดิม หรือเพิ่ม object ใหม่ทั้งก้อนถ้าเป็นหุ้นแม่ตัวใหม่

## รันบนเครื่อง

เปิดผ่าน server เท่านั้น (เปิดไฟล์ตรงๆ `fetch` จะโดน browser block):

```
npx http-server -p 8123
```

แล้วเข้า http://localhost:8123

## ข้อจำกัด

ข้อมูล ณ ก.ค. 2569 เรียบเรียงจากรายชื่อ DR ของตลาดหลักทรัพย์แห่งประเทศไทย คำอธิบายธุรกิจเป็นสรุปอย่างย่อ ควรตรวจสอบข้อมูลล่าสุดกับผู้ออกก่อนตัดสินใจลงทุน
